# BeerLab

Веб-приложение на React для доставки пива и закусок с адаптивной вёрсткой и фильтрацией каталога.

## Стек
- React + Vite
- Управление состоянием через Context API
- Serverless-функция на Vercel для безопасного проксирования Telegram Bot API
